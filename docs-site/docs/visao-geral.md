## Sobre o Projeto

&emsp;A **Programmable ECU** é uma unidade de controle eletrônico de código aberto desenvolvida pelo **TechGears**, clube universitário do [Inteli — Instituto de Tecnologia e Liderança](https://www.inteli.edu.br). O projeto controla injeção de combustível e ignição em motores de combustão interna de 4 cilindros via microcontrolador ESP32, com interface de calibração web e telemetria em tempo real.

&emsp;O TechGears une teoria e prática para desenvolver soluções inovadoras em Engenharia Mecatrônica, capacitando seus membros para os desafios reais da indústria de veículos.
